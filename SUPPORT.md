# Getting help

- Installation: [quick start and Docker](docs/install.md).
- Bugs: use **Help → Request support…**, or the [bug form](https://github.com/mevlt01001/GstPipeStudio/issues/new?template=bug_report.yml).
- Missing features: describe one task and the expected result in the feature form.
- Device compatibility: use the hardware report form, even if the result is a failure.
- Vulnerabilities: follow [SECURITY.md](SECURITY.md).

Include the app version/commit from About, Ubuntu and GStreamer versions, installation method and a minimal pipeline. Remove passwords, private addresses and personal media before posting. Maintainer time and hardware coverage are limited; reports and small verified pull requests are especially helpful.
