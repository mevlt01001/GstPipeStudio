# GstPipeStudio 0.3.0 — visual pipeline inspection and desktop improvements

GstPipeStudio is an early-stage visual editor for GStreamer pipelines. This release improves building and inspecting a pipeline on the canvas.

- Compare processing timing, buffer timestamp age and QoS-reported Drop Rate across elements.
- Inspect queue occupancy and live graphs using camera-free sample pipelines.
- Reset individual properties or all editable properties; wheel edits require a deliberate hover.
- Use the unified window header, animated About screen, larger file picker and connected-element movement.
- Identify the version, commit, runtime and executable path from About. Development builds use separate settings.

**Install:** choose the `.deb` matching Ubuntu 20.04/22.04/24.04 and x86_64/aarch64 from this release. Verify its `.sha256`, then install with `sudo apt install ./downloaded-file.deb`.

**Docker:** `ghcr.io/mevlt01001/gstpipestudio:0.3.0` is Ubuntu 22.04 / amd64. Linux GUI access requires display forwarding; see the repository's installation guide and launcher rather than running a bare container command. Additional Ubuntu runtime tags belong to the next release workflow and are not part of 0.3.0.

**Limits:** processing timing is first input to first output, including waiting. Drop Rate requires buffer-unit QoS counters; it does not identify the exact internal stage of a drop. GPU, Jetson and camera compatibility require device-specific testing. Import reconstructs a launch description; it does not attach to a running external process by name.

Please report one small reproducer and your app/GStreamer versions, or contribute a hardware compatibility result.
